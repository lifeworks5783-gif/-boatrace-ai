# 固定PDCA研究テーマ：風神雷神 × 予測順位帯 × 高配当条件付き確率 × ユーザー選択式買い方

**制定日：2026-10-14｜状態：毎日の夜PDCA固定検証項目｜本番予測・購入設定の変更なし**

## 1. プロダクト目的と大原則

予測AIは通常スコア、直前スコア、風神・雷神発動、専用AIの3連単全組合せ順位を生成する。既存の予測ロジックはこの研究で変更しない。その後の「購入戦略・確率提示エンジン」で、**当該シグナルの下、どの買い目の集合で何%の確率で3連単が的中し、5,000円以上または10,000円以上の払戻が発生するか**を研究して提示する。

最終製品の買い方・購入順位・点数・投資額・見送りは**利用者が選ぶ**。AIは候補別の推定値、根拠、過去実績、母数、リスクを表示するが、「この買い目が必ず当たる」と断言しない。自動購入・自動賭けは今回の対象外。

## 2. 条件付き確率と母数の厳密な定義

- `S`：レース開始前に判定した風神Lv0〜3×雷神Lv0〜3（全16分類）。`X`：当該レースの**締切前に入手可能な**スコア分布・場・気象・展示・オッズ等。
- `W`：実際の3連単が専用AIで何位か（1〜120位、5艇立てでは1〜60位）。
- `T`：順位帯（1-6 / 7-12 / 13-24 / 25-48 / 49-72 / 73-120、必要に応じ4・5層も並行研究）。
- `H5`：100円あたり実際の3連単払戻5,000円以上。`H10`：同10,000円以上（万舟）。
- `K`：利用者が選んだ重複なしの3連単順位集合。24点のほか6/8/12/18点等にも対応。`Y(K)`：W∈K、つまり**選択した買い目の的中**。

必須指標：
1. `P(H5|S,X)` と `P(H10|S,X)`：そのシグナル・事前情報で5,000円以上/万舟になる確率。
2. `P(W∈T | H5,S,X)` / `P(W∈T | H10,S,X)`：高配当が出る場合、的中がどの順位帯に入るか。
3. **`P(H5∩(W∈T)|S,X) = P(H5|S,X) × P(W∈T | H5,S,X)`**。万舟もH10に置き換えて計算。これは「順位帯全体を購入した場合に高配当を的中させる確率」に対応し、個別数点だけを買う確率とは違う。
4. **`P(Y(K)|S,X)`**：利用者が実際に選択した全買い目Kの的中確率。
5. **`P(H5∩Y(K)|S,X)` / `P(H10∩Y(K)|S,X)`**：利用者選択Kで5,000円以上・万舟を「実際に的中」させる確率。**最終製品で最も重要なK固有の表示指標**。
6. `P(S|H5)` と `P(S|H10)`（全体の高配当をそのシグナルが捕捉した割合）は**監査用の捕捉率**。**`P(S|H) × P(W∈T|H,S)` は `P(H∩T|S)` ではない**。捕捉率と条件付き発生率を混同しない。
7. `E[return(K)|S,X]`＝締切前時点の推定的中確率と購入可能な推定払戻額から計算した期待払戻（※締切前オッズとの連携が可能な場合のみ）。`EV`＝期待払戻－100円×購入点数。**払戻が5,000円以上となる確率は、購入利益がプラスとなる確率とは別指標**。複数点購入の投資額を必ず控除。
8. 各表示は標本数（分母・分子）、対象期間、モデル版、推定方法、区間推定/信頼度、締切前か事後復元か、検証開始日を必ず併記する。

## 3. 研究用の確率表示例（実データに基づくが未来の個別レース予測ではない）

2026-10-07〜13の`F0R1`、**69レース**で3連単払戻5,000円以上31R、万舟19R。研究専用AIの実着順位が「25〜48位」の**24通りの帯全体**に入った5,000円以上は9R、万舟5R。したがって：
- `P(H5|F0R1)` の**過去実績**＝31/69＝44.93%。
- `P(W∈[25,48] | H5,F0R1)`＝9/31＝29.03%。
- 帯全体で5,000円以上を的中する**過去実績**＝(31/69)×(9/31)＝**9/69＝13.04%**。
- 帯全体で万舟を的中する過去実績＝**5/69＝7.25%**。
- 一方、`K∩[25,48]={25,30,36,42,48}`の**5点だけ**では、5,000円以上は**1/69＝1.45%**、万舟は**0/69＝0%**。**帯全体の13.04%を、帯内の選択5点の確率として表示してはならない**。
- 例の研究用`F0R1`24点K全体では、実着的中**34/69＝49.28%**、5,000円以上的中**7/69＝10.14%**、万舟的中**3/69＝4.35%**。100円×24点で紙上払戻176,760円、投資165,600円、ROI106.74%。**小母数・過去結果を見て設計された配分・一時的な配当集中の影響を含み、将来の回収率/的中率を示すものではない**。

上記は「期間内過去割合」であって、個別レースが同条件なら同確率であることの証明ではない。個別レース表示はXを使い、時系列・校正評価を通過した推定のみ「このレースの推定確率」と呼ぶ。未達なら「過去実績」か「推定保留」と表示。

## 4. 製品画面の設計（例示）

レース上部：通常AIの6艇スコア／風神・雷神Lv／専用AI120順位・見送り可能。

「シグナル×高配当の見通し」カード：
- シグナルF0R1
- 5,000円以上：**推定（%）**／万舟：**推定（%）**。推定未検証なら「過去69R：44.93%／27.54%」と別表示。
- 強本線・本線・準本線・中穴・穴・大穴ごとに、**帯全体の過去高配当同時発生率・帯幅・予測順位・推定期待払戻**を並べる。
- 4層／5層／6層／現行上位24点／シグナル別動的配分から「買い方候補」をユーザーが比較。各候補には**実際に選択された順位と3連単組合せ**を明示。
- 購入点数・投資額を入力または選択。**選択Kの3連単的中率／5,000円以上の的中率／万舟的中率／想定損益・回収率（算出可能なら）／不確実性**を再計算表示。
- ユーザーが各順位を追加・削除・階層配分を変更して比較できる。購入を指示しない、購入しない選択肢も常時表示する。
- 各レースで「データ不足」「精度未検証」「時点整合未確認」は数値に警告を付ける。過去実績と将来推定、万舟発生率と万舟**的中率**を分けてラベル表示。

## 5. 毎日の固定PDCA

1. 前日・直近7日・30日・90日・可能な全期間について、F0R0〜F3R3の**16分類を省略せず**、発動数/シグナル捕捉率/高配当発生率を集計。
2. 各シグナルについてS1〜S6（必要なら4/5層）の「高配当条件付き順位分布」と「帯幅で補正した1順位あたり密度」「配当帯別平均/中央値順位」を計算。
3. 固定上位24点、固定分散24点、シグナル別動的24点、購入者選択K（6/8/12/18/24点など）を**実際に選んだ順位**で精算し、全体的中率、5千円・万舟の的中率、投資、払戻、損益、ROIを比較。
4. シグナルごとに買い方と**購入階層の配分**を提示。ただし、買い目点数を増やすだけで的中が増えた成果を「投資効率改善」と混同しない。
5. 学習期間・期間を後で見て調整した探索期間・未来の未見期間を区別。翌日のレースを予測する時は**当該レースの締切より前に保存された情報と、前日までに確定した学習データだけを使用**。過去の当日結果を入力した事後再構成予測を実戦成績としない。
6. シグナル×6層×高配当閾値の小標本への過学習を避け、階層ベイズまたは全体分布に縮約する平滑化、Wilson区間/ベイズ区間、標本数に応じた表示停止、予測の校正（Brier/log-loss/reliability diagram）とROIの配当感度を監査。
7. 成績が改善した場合でも**本番の予測スコア・シグナル発動条件・既存AIの買い目生成を自動変更しない**。研究版で新たな購入提案器のみ検証、採否は利用者承認が前提。
8. 専用AIが未発動のF0R0では順位別専用確率を0%と表示せず「未適用」、通常AIベースの別途参考集計を提供する。
