# 選手・直近調子データ蓄積仕様

## 目的
直近調子が実着順および予測の○→×／×→○に関係するかを、将来検証できる状態にする。現時点では本番配点に追加しない。

## 継続保存する特徴量
features/racer_features.csv を正本として、登録番号単位で以下を更新する。
- 直近5走・10走: 平均着順、1着率、2連対率、3連対率、平均ST
- 30日・90日: 平均着順、1着率、2連対率、3連対率、平均ST
- F/L件数・率、展示サンプル・平均展示
- 30日対90日のトレンド差（既存trend列）

## 検証時の結合キー
- registration_no
- target date / as_of_date
- race_id・艇番（当日のprogram/prediction側）

## PDCAルール
- 当日結果を特徴量作成に混ぜない（必ずレース前時点まで）。
- 欠損を0として扱わない。
- ○→×／×→○診断では、入れ替わった2艇の直近5/10/30/90差を比較する。
- サンプル蓄積中は独立配点0%。明確な再現傾向が出た場合のみ補正候補として全体副作用を検証する。
