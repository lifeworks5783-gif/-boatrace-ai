# PDCA運用ルール

更新日: 2026-10-09

## 目的
予測ロジックの改善を短時間で継続し、未解決事項を放置せず、翌日のPDCAへ正確に引き継ぐ。

## 1. 毎回のPDCA終了条件
各テーマは必ず次のいずれかまで到達して終了する。
- 採用: 本番反映に十分な根拠あり
- 却下: 改善なし、または副作用が大きい
- 継続検証: 未解決だが、原因仮説・次の検証方法・判断基準まで決定済み

「原因不明のまま保留」「次回また考える」では終了しない。

## 2. 検証ルール
- 配点変更 = 全対象レースで全体検証
- 内部条件・補正変更 = 影響対象を重点検証し、最後に全体副作用確認
- 本番ロジックは検証途中で変更しない
- 主要評価: 1着、勝者TOP2、勝者TOP3、TOP3完全一致、着順一致、勝者平均予測順位、回収率、日別安定性
- x→o / o→x は原因診断用であり、配点変更の主判定には使わない

## 3. 時間管理
1テーマを長時間追い続けない。
1) 仮説
2) 最小検証
3) 改善傾向あり → 対象拡大
4) 改善傾向なし → 却下または別仮説
の順で進める。
外部取得障害などで停滞した場合は、同じ方法の再試行を繰り返さず代替経路を決める。

## 4. 毎日の議事録
PDCA終了時に日付単位で以下を保存する。
- 今日検証したテーマ
- 現行仕様
- 仮説
- 使用データ・対象レース数
- 比較結果
- 採用 / 却下 / 継続検証
- 判断理由
- 本番変更の有無
- 発見した問題
- 解決策
- 翌日へ繰り越す項目
- 翌日の最初の作業
- 採用判断基準

## 5. 翌日への繰り越し
繰り越し項目には必ず
「何が未完了か」「なぜ未完了か」「次に何をするか」「どの結果なら採用/却下するか」
を記録する。

## 10. 毎日必須：ChatGPT独自予測／独自シグナル／買い目の第三者視点研究（2026-10-14追加）

**毎回の夜PDCAで省略しない。** 通常スコア／風神雷神の微調整だけを検証するのではなく、ChatGPTの独立した仮説を、既存方式と同一レース・同一購入条件で比較する。

### 固定報告事項（毎日）
1. 独自予測モデルのバージョン、数式、係数、利用した特徴量、採用・非採用の理由。既存要素だけでなく、新しいデータ要素（直前オッズ、選手×コース交互作用、気象・場・季節、情報信頼度、スコア較正）も毎回候補として検討し、未取得は未取得と明記する。
2. 独自シグナル（発動前に判断できる条件、発動件数、対象艇の1/2/3着率、TOP3率、的中・万舟・5千円超捕捉、誤発動、シグナルなしとの比較）。
3. 独自買い目：三連単候補の順序と全点数、6/8/12点・条件分岐・買い／見送り、1点100円の仮想投資と払戻・損益・回収率を現行フォーメーション／BOX／通常AI8点／シグナルAI24点と**別会計**で比較。
4. 単日・直近7日・同一モデル版累計。1着一致、勝者TOP3、TOP3集合一致、3連単順序一致を区別。
5. **実レースによる立証・反証**：最低でも改善例と悪化例のレースID、各艇の入力値、予測時点の採点内訳、全候補の買い目、公式着順、公式払戻、復元元を紐付ける。参照元へのリンクを毎回付ける。
6. 評価母数・5艇立て・事後復元・時刻未確認、除外理由、結果リーク監査。事後復元は研究観測に使うが当時のリアルタイム購入成績と混同しない。
7. ChatGPTによる独立した**最良候補と判断理由**、現行との差、反証、次の具体的検証、採用／却下／継続検証。候補不十分なら「まだ最良と判定不能」と記録する。

### 現行の独立研究仮説 V1（係数固定・採用前）
- 設定正本 `config/research/chatgpt_independent_strategy_v1.json`。
- 朝スコア65%＋直前スコア35%＋同一レース内展示タイム偏差値相当（zを±2で制限し1.5点/標準偏差）。これらの係数は**研究初期仮説であり優位性が確立した数値ではない**。直前スコアにも展示要素が含まれているため二重計上の可能性を単体要素比較で点検。
- 三連単はPlackett–Luce型の重複なし条件付き順位モデルで全候補を並べる。勝率の較正を検証する前に「正確な購入確率」や「期待値」と表現しない。
- 合意強軸＝独自1位と朝1位一致、独自1位と2位に8点以上差、展示進入1～3コース、展示Fなし。研究用に上位6点を試算。
- 穴浮上＝朝1位ではない艇が独自1位、かつ直前－朝スコアが5点以上。研究用に上位12点を試算。残り上位8点。
- 通常の固定6/8/12点、上記条件分岐、見送りを別々に検証。**市場の締切前オッズが監査できない間は、買うべき「正の期待値」の証明はできない**。
- 計算：`collectors/evaluate_chatgpt_independent_pdca.py --date YYYYMMDD`。出力：`evaluations/chatgpt_independent_pdca/daily/YYYYMMDD/REPORT.md`・`summary.json`・`race_evidence.jsonl` と最新集計。
- 日々の固定レポートでは、数値自動集計に加えてChatGPT自身が結果を解釈し、実際にどの仮説を次回検証するか提案する。コードの定型集計だけを「ChatGPTが独立思考した」とは扱わない。

### 本番採用ゲート
採用候補はデータの前後関係を守った独立期間で、最低7完了日・同一対象レース母数・前向きの保存時刻監査を実施する。単体要素の有効性、日別安定性、買い点数別の回収率と信頼区間、少数高配当への依存を検証する。採用決定と本番実装は**必ずユーザーの明示承認後**に限る。今日の結果から当日中に係数を合わせ込んで、その同じ日をホールドアウトと呼ばない。
