# 全国・当地差分データ蓄積仕様

## 目的
全国成績と当地成績の差が予測の○→×／×→○に関係するか、後から検証できるように継続保存する。

## 固定定義
- 全国勝率: program_entries の national_win_rate
- 全国2連対率: national_top2_rate
- 当地勝率: local_win_rate
- 当地2連対率: local_top2_rate
- 勝率差: 当地勝率 - 全国勝率
- 2連対率差: 当地2連対率 - 全国2連対率
- 正値ほど「全国平均より当地で強い」、負値ほど「当地で弱い」。

## 運用
- これは収集・診断用。現行本番の全国2連対率15%は変更しない。
- 毎日の program_entries から差分CSVを生成し、登録番号・race_id・艇番と紐付ける。
- 将来、朝→直前の○→×／×→○診断へ差分を結合する。
- サンプルが増えるまで配点化しない。
- 欠損は0扱いせず欠損のまま保存する。
